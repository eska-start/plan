# 지도 탭 3가지 기능 협업 구현안

요청 기능:
1. 목록 보관함(날짜 미정) → 날짜별 배치
2. 주변 관광지 바로 추천
3. 동선 자동 최적화

---

## 1) 목록 보관함(날짜 미정) → 날짜별 배치

### 목표
- 지도에서 저장해 둔 장소를 `날짜 미정` 상태로 모아두고,
- 나중에 Day 1/2/3 같은 특정 날짜로 이동 배치.

### 구현 방식 (권장)
- `itineraryItems`에 `status` 컬럼 추가:
  - `planned`: 날짜에 배치된 일정
  - `pool`: 날짜 미정 보관함
- `date`는 `planned`일 때만 필수처럼 사용.

### 서버 작업 (Agent)
- `listByDate`: `status = planned` 조건 추가.
- `listPoolByTrip` 라우터 추가.
- `moveFromPoolToDate` 라우터 추가 (`id`, `date`, `order`).

### 프론트 작업 (Agent)
- Map 탭에 `보관함` 패널 추가.
- 카드 액션:
  - `보관함으로 이동`
  - `이 날짜로 배치`

### 당신이 하면 좋은 일 (User)
- 보관함 동작 정책 결정:
  - Day별 최대 개수 제한 여부
  - 보관함 기본 정렬(최근 저장순 / 이름순)
  - 보관함 카드에 보여줄 최소 정보(메모 포함 여부)

---

## 2) 주변 관광지 바로 추천

### 목표
- 현재 선택한 장소(또는 지도 중심점) 기준 반경 내 추천 장소를 즉시 제안.

### 구현 방식 (권장)
- 서버에 `itinerary.nearbyRecommend` 라우터 추가:
  - 입력: `tripId`, `lat`, `lng`, `radiusMeters`, `category`
  - 출력: 추천 장소 배열(이름/주소/좌표/평점/거리)

### 서버 작업 (Agent)
- 외부 POI API 연동(예: Google Places Nearby Search).
- 결과를 공통 스키마로 정규화.

### 프론트 작업 (Agent)
- Map 탭에 `근처 추천` 버튼.
- 추천 리스트 모달:
  - `이 날짜에 추가`
  - `보관함에 저장`

### 당신이 하면 좋은 일 (User)
- 추천 반경/카테고리 기본값 확정:
  - 반경: 1km/2km/3km
  - 카테고리: 명소/카페/식당/쇼핑
- POI 제공사/API Key 준비 및 쿼터 확인.

---

## 3) 동선 자동 최적화

### 목표
- 같은 날짜 일정 순서를 자동 정렬해 이동시간 최소화.

### 구현 방식 (권장)
- 현재 날짜 아이템을 입력받아 최적 순서 계산 후 `reorder` 호출.
- 초기 버전:
  - Nearest Neighbor + 2-opt
- 고급 버전:
  - 거리/시간 매트릭스 기반 비용 최소화

### 서버 작업 (Agent)
- `itinerary.optimizeRoute` 라우터 추가:
  - 입력: `tripId`, `date`, `mode(walk|drive)`
  - 출력: `orderedIds`, `summary(총 시간/거리)`

### 프론트 작업 (Agent)
- Map 탭에 `동선 최적화` 버튼.
- 적용 전/후 비교 UI(총 이동시간 표시).
- `적용` 시 기존 `reorder` 로직 재사용.

### 당신이 하면 좋은 일 (User)
- 최적화 기준 확정:
  - 도보 우선 / 차량 우선 / 혼합
- 고정 지점(절대 순서 유지) UX 필요 여부 결정.
